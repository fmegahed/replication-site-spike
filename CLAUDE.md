## Replication record

- This project keeps a replication record. Use the replication-materials skill.
- Write specs, plans and ledgers to `replication_materials/plans/`. Use the file names `YYYY-MM-DD-<topic>-<kind>.md`. This replaces `docs/superpowers/`.
- Add a decision row to `replication_materials/project/decisions.md` when a person or Claude Code decides something.
- Add a process row to `replication_materials/project/process.md` at each change of stage.
- Commit and push changes that touch only `replication_materials/` to `main` without asking. Do not put code in these commits.
- Make no paid API call without a budget row in `replication_materials/calls/README.md`.
- Write records in 80% ASD-STE100: short sentences, active voice, no contractions.
